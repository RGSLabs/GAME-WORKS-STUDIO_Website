# GAME WORKS STUDIO™ - Official Website

Independent Animation & Game Development Studio

## 🚀 Quick Start

1. Replace images in `/img/` with your actual assets
2. Update YouTube video IDs in `index.html` (search for `YOUTUBE_VIDEO_ID_X`)
3. Edit `js/blog-posts.json` with your blog content
4. Deploy to GitHub Pages

## 📝 Blog

To add blog posts:
1. Open `blog-admin.html` in your browser
2. Fill out the form
3. Copy the generated JSON
4. Replace content in `js/blog-posts.json`
5. Commit and push

## 🌐 Deployment

### GitHub Pages (Free)

1. Create a repository named `yourusername.github.io`
2. Upload all files to the root
3. Go to Settings → Pages → Source: main branch
4. Your site will be live at `https://yourusername.github.io`

### Custom Domain (Optional)

1. Add your domain to `CNAME` file
2. Configure DNS: CNAME record pointing to `yourusername.github.io`
3. Enable HTTPS in Settings → Pages
